## 记录规则

1. 一票一行，必须是**真实单据或真实业务方提供的东西**（可脱敏）。
2. 每条反馈要能追到一次代码/规则/文档改动，否则不算"闭环"。
3. 复测数据写在同一行，不做"改了但没验"。
4. 隐私：企业名、单号一律脱敏为占位符（如 `A 公司`、`INV-****`）。

## 怎么快速补满 5 条（半天能做的事）

1. 找一个货代/报关行的朋友，给他 **2 票**脱敏过的单证（或让他自己挑 2 票废单）。
2. 只问三个问题：
   - 这 29 条里，哪几条你会真的改？
   - 哪几条是"报了也不改"的噪声？
   - 你还想让它查什么（现在没查的）？
3. 把答案逐条落到上表，并对应到「改动」列：加规则 / 降噪 / 改提示词 / 加字段。
4. 复测时用同一份单证重跑，把"改前 → 改后"的条数写进复测列。
